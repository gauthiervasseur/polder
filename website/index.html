How it works

From CSV to insight in three steps

  1. 1

    Load a CSV

    Click Load CSV or drop a file anywhere on the window. Polder sorts the columns into Dimensions (text, dates, IDs) and Measures (numbers).

  2. 2

    Drag fields onto shelves

    Industry to Columns, Financed Amount to Values, Region to Color, and you have a stacked bar chart. Click a pill to switch Sum to Average, or Year to Month.

  3. 3

    Pivot, filter, share

    Choose Table for a pivot table, stack dimensions on rows and columns, turn on heat shading, and drop fields on Filters to zoom in. Export the result for your deck.

Shortcuts

  • Drag field → shelf: add it
  • Drag pill off its shelf: remove it
  • Double-click field: add it to the best shelf
  • Right-click field: more options
  • Click pill: aggregation or date level
  • Click table header: sort

Themes

DLL blue by default, any brand on demand

The interface follows DLL's look. Charts and tables follow a theme, which is a CSS file: DLL, DLL Night, or your own.

partner-brand.css
/* every line is optional */
@import url("https://fonts.googleapis.com/css2?family=Inter");

:root {
  --polder-font-family: "Inter", sans-serif;
  --polder-font-size: 13px;
  --polder-text-color: #333333;
  --polder-background: #ffffff;
  --polder-grid-color: #e5e5e5;
  --polder-palette: #0099ff, #f28c28, #00875a, #4b08a1;
  --polder-sequential: #e0f2ff, #005c99;
  --polder-table-header-background: #0099ff;
  --polder-table-header-color: #ffffff;
}

How it works

  • Load it with Theme CSS, or drop the .css file on the window.
  • Polder reads --polder-* variables, plus plain font-family, color and background on :root or body.
  • Web fonts work through @import or @font-face. If DLL's Effra font is installed, Polder uses it.
  • Up to 8 palette colours. Each value keeps its colour when you filter, and extra values fold into "Other".
  • Dark mode switches the interface and flips DLL ↔ DLL Night for the charts.

Examples: dll.css · dll-night.css · corporate.css · arcade.css · editorial-webfont.css

Why "Polder"?

DLL stands for De Lage Landen, "the Low Countries". A polder is the Dutch answer to the sea: low land, diked and drained, turned into fields that feed a country. Polder does the same for data. It reclaims insight from a sea of rows. The icon shows a tractor (equipment finance, where DLL started) crossing a field that rises like a bar chart (growth).

FAQ

Can I open Excel files?
Save the sheet as CSV first (File › Save As › CSV). Polder works with one CSV file at a time.
How big can the file be?
Polder keeps the whole file in memory. On a recent laptop, a 300,000-row (10 MB) file loads in under a second and pivots redraw in a fraction of a second.
Is my data uploaded anywhere?
No. Everything happens inside your browser, even in the online version.
Is the demo data real?
No. Lowlands Asset Finance is invented, and every contract and amount in it is generated.
